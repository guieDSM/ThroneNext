# Проверка маршрута вкладки Chrome

Локальное расширение для Throne: собирает сетевые обращения **одной выбранной вкладки**, включая встроенные плееры и iframe. Показывает все замеченные домены, число запросов и ошибки; отдельным списком — данные, которые уйдут в Throne.

## Установка

Откройте `chrome://extensions` → «Режим разработчика» → «Загрузить распакованное расширение» и выберите эту папку. После обновления файлов нажмите «Обновить» на карточке расширения.

## Проверка сайта

1. В Throne откройте «Добавить исключение» → «Сайт / IP» и введите адрес страницы.
2. В Chrome откройте эту страницу, закройте DevTools и нажмите «Начать захват» в расширении. Страница перезагрузится. Воспроизведите проблему, например запустите плеер.
3. Снова откройте расширение: блок «Куда обращалась вкладка» показывает домены и ошибки; «Что передаётся в Throne» — домен сайта, домены ошибок и число блокировок браузером.
4. Нажмите «Завершить и передать». В Throne проверьте кандидатов и сохраните нужные. Если окно Throne было закрыто, откройте его и нажмите «Повторить передачу» без нового захвата.

Захват заканчивается после завершения или через три минуты. Расширение не собирает ссылки из HTML, по которым вкладка не обращалась. Полные URL, параметры, cookies и тела ответов не сохраняются и не передаются; список доменов остаётся в сессионном хранилище Chrome. Throne получает только домен сайта, домены и типы сетевых ошибок, число блокировок — через `127.0.0.1:18472`. Ошибка, в том числе HTML-страница `404 Not Found` с кодом HTTP 200, лишь повод проверить маршрут, а не подтверждение его причины.
