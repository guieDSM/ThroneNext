# Проверка перед публикацией

Публикуйте только исходники из этого каталога. Папки установленного клиента, его data, профили, подписки, базы данных, журналы, диагностику, резервные копии, сертификаты подписи и сборки не копируйте сюда.

Перед каждым коммитом просмотрите список файлов (git status --short, затем git diff --cached --name-only) и изменения (git diff --cached). Отдельно проверьте новые тесты, примеры, скрипты и документацию на реальные адреса серверов, ссылки вида vless://, ключи, токены, адреса почты и локальные пути. .gitignore не защищает файлы, уже добавленные в Git.

При обнаружении секрета не публикуйте этот снимок. Удаление секрета новым коммитом не удаляет его из прежней истории: подготовьте чистую историю и замените скомпрометированный ключ или ссылку.
